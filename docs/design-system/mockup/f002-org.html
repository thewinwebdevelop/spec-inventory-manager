รอบแก้ 2026-07-28 (หลังรีวิว) — ของที่ "ไม่เคยประกาศ" ถูกดึงกลับเข้า design system
รอบแรกมี variant/ขนาด/สถานะที่ mockup เดาค่าเอง ไม่มีใน docs/design-system.md ⇒ แก้แล้วทั้งหมด และเขียน diff ไว้ที่ ui.md §7:
1) ปุ่มในกล่องสถานะใช้โทนของกล่องนั้น (ตัวอักษร = <tone>.text · ขอบ = currentColor 65%) — เดิมเป็นเทากลาง+ตัวอักษรสีปกติ จึงดูหลุดออกจากกล่องแดง
2) focus ring มี token แล้ว (focus.ring.w 2.5px · offset 2px · :focus-visible เท่านั้น) และเลิกโชว์ค้างใน mockup — ใช้ป้าย "ภาพจำลอง" แทน (S8-3)
3) color.info.* เป็น role จริง (bg/border/text) ทั้ง light+dark — เดิม tone info ถูกประกาศไว้ใน ui.md §2 แต่ไม่มี token
4) ไอคอน = inline SVG outline ทั้งหมด (grid 24 · stroke 2 · currentColor · ขนาด 16/20/24/40) — ไม่มี emoji เหลือในจอแล้ว · ชุดไอคอนจริงรอ user เคาะ (ui.md §7 ข้อ 5)
5) tlink = Button variant="tertiary" สี color.primary + ขีดเส้นใต้ตอน hover/focus + พื้นที่แตะ 44px
6) tap target: 27 จุดที่เคยต่ำกว่า 44px ถูกแก้หมด — btn-sm นิยามใหม่ว่า "แน่นที่ตัวอักษร/ระยะข้าง แต่สูง ≥44px เสมอ" (ไม่มีข้อยกเว้น pointer-only)
7) base style + theme token ย้ายไปที่ body (เดิมผูกกับ .pg) — กันบั๊กแบบเดียวกับที่เจอ เมื่อ Next.js portal ออกไป document.body
